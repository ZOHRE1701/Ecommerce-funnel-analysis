# E-Commerce Funnel Analysis

## Project Overview
This project analyzes the e-commerce customer journey to understand user behavior and identify where potential customers drop off during the purchasing process.

## Tools & Technologies
- SQL
- Looker Studio

## Analysis Objectives
- Analyze user activity throughout the purchasing journey.
- Calculate conversion rates between funnel stages.
- Identify stages with the highest customer drop-off.
- Evaluate the overall session-to-purchase conversion rate.

## Funnel Stages
1. Session Start
2. Product View
3. Add to Cart
4. Begin Checkout
5. Shipping
6. Payment
7. Purchase
